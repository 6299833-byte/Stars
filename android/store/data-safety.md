# Безопасность данных — ответы для Play Console

Play Console → «Контент приложения» → «Безопасность данных».

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение или передаёт какие-либо из обязательных типов пользовательских данных? | **Нет** |
| Все ли собираемые данные шифруются при передаче? | Не применимо (данные не собираются) — форма пропускает этот вопрос после «Нет» |
| Можно ли запросить удаление данных? | Не применимо |
| Ссылка на политику конфиденциальности | URL опубликованного `privacy-policy.md` |

Итог в карточке: «Разработчик заявляет, что приложение не собирает и не передаёт данные пользователей».

Обоснование (для проверки перед отправкой):
- в `AndroidManifest.xml` разрешение `INTERNET` удалено (`tools:node="remove"`), других разрешений нет;
- весь контент (`www/`: HTML, изображения Rubin, шрифты) упакован в APK/AAB, внешних запросов нет;
- нет рекламы, аналитики, Firebase, crash-репортеров; плагины Capacitor не подключены (кроме ядра);
- внешние ссылки на вкладке «О проекте» открываются в браузере пользователя — это не передача данных приложением.

Если в будущем добавятся сеть, аналитика или отчёты о сбоях — форму нужно пересмотреть **до** выпуска такой версии.

Связанные разделы «Контента приложения»:
- **Реклама:** «Нет, приложение не содержит рекламы».
- **Доступ к приложению:** «Все функции доступны без ограничений» (входа нет).
- **Целевая аудитория:** см. `content-rating.md`.
- **Новостное приложение:** нет. **Приложение для отслеживания контактов/статуса COVID-19:** нет. **Государственное приложение:** нет. **Финансовые функции:** нет. **Здоровье:** нет.
- **Идентификатор рекламы (Advertising ID):** не используется (targetSdk 36 — ответить «Нет»).

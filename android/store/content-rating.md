# Возрастной рейтинг (IARC) — ответы для Play Console

Play Console → «Контент приложения» → «Возрастные ограничения» → анкета IARC.

- **Адрес эл. почты для связи IARC:** _эл. почта разработчика_
- **Категория:** «Справочные, новостные или образовательные приложения» (Reference, News, or Educational)

| Вопрос анкеты | Ответ |
|---|---|
| Насилие (в т. ч. мультяшное, реалистичное, кровь) | Нет |
| Страх / пугающие сцены | Нет |
| Сексуальный контент, нагота | Нет |
| Ненормативная лексика, грубый юмор | Нет |
| Наркотики, алкоголь, табак | Нет |
| Азартные игры, симулированные азартные игры | Нет |
| Пользователи могут общаться / обмениваться контентом (чат, UGC) | Нет |
| Приложение передаёт местоположение пользователя другим | Нет |
| Покупки в приложении / цифровые товары | Нет |
| Неограниченный доступ в интернет (браузер, поиск) | Нет (внешние ссылки открываются в системном браузере, сам браузер не встроен) |
| Является ли приложение веб-браузером или поисковиком | Нет |

Ожидаемый результат: **IARC 3+ / PEGI 3 / ESRB Everyone / USK 0 / «0+»** для RU.

## Целевая аудитория и контент

Раздел «Целевая аудитория»:
- Рекомендуемый ответ: возрастные группы **13–15, 16–17, 18+**. Приложение подходит детям, но если отметить группы младше 13, приложение попадает под требования программы «Для всей семьи» (Families Policy): проверка политики для детей, ограничения на SDK, отдельное ревью. Требования выполнимы (данных нет, рекламы нет), но это дольше. Если владелец хочет ориентироваться на детей — отметить также **9–12** и/или **6–8**, и ответить в анкете Families, что рекламы и сбора данных нет.
- «Может ли приложение непреднамеренно привлечь детей?» — честно: **Да** (космос, яркая графика) — тогда Play попросит подтвердить, что нет рекламы/сбора данных; ответить, что нет.

# Живые обои «Солнечная система» для Windows

Солнечная система на рабочем столе. Справа часы, встречи из календаря Outlook и новые сообщения из Outlook и WhatsApp Web. Камера сама медленно облетает планеты.

Работает так:

```
Outlook в интернете ──(ссылка ICS)──┐
                                     ├─► stars_helper ──► http://127.0.0.1:8777/#wallpaper ──► Lively Wallpaper
Уведомления Windows ─(только чтение)┘   (на твоём компьютере)
```

Помощник `stars_helper` работает только на твоём компьютере и слушает только адрес `127.0.0.1`. Наружу он ничего не отправляет, кроме скачивания твоей же ссылки на календарь.

---

## 1. Скачай

На странице https://github.com/6299833-byte/Stars/actions открой последнюю зелёную сборку **«Windows wallpaper»** и скачай артефакт **stars-wallpaper-windows**. Распакуй его в постоянную папку, например `C:\Stars`. В ней будут:

- `stars_helper.exe` — помощник;
- `www\` — обои (страница, снимки, шрифты);
- `config.json` — настройки.

Можно и без `.exe`: установи Python 3 из Microsoft Store и запускай `start.bat` из папки `desktop`. Тогда собери `www` командой `npm run build` или возьми папку `www` из архива проекта.

## 2. Ссылка на календарь Outlook (ICS)

1. Открой Outlook в браузере: https://outlook.office.com (рабочий аккаунт) или https://outlook.live.com (личный).
2. Шестерёнка → **Календарь** → **Общие календари** → **Опубликовать календарь**.
3. Выбери календарь и уровень доступа **«Может просматривать все сведения»** (или «…только время, когда я занят», если не нужны названия), нажми **Опубликовать**.
4. Скопируй ссылку **ICS** и вставь в `config.json` в поле `"ics_url"`.

Если в рабочем аккаунте нет пункта «Опубликовать календарь», значит, компания его отключила. Тогда календарь можно подключить через Microsoft Graph, но для этого нужно согласие администратора. Напиши, если нужен этот вариант.

> Ссылка ICS даёт доступ к календарю любому, у кого она есть. Не публикуй её и не пересылай.

## 3. Уведомления Outlook и WhatsApp Web

Помощник читает уведомления Windows (файл `%LOCALAPPDATA%\Microsoft\Windows\Notifications\wpndatabase.db`, только чтение). Поэтому нужно, чтобы уведомления **появлялись в Windows**:

- **WhatsApp Web:** открой https://web.whatsapp.com в Edge или Chrome, нажми «Включить уведомления» и разреши их браузеру. Вкладку держи открытой (можно свернуть). В Windows: «Параметры» → «Система» → «Уведомления» → включи для Microsoft Edge или Google Chrome.
- **Outlook:** в новом Outlook или Outlook в браузере включи уведомления о новых письмах (Настройки → Общие → Уведомления). Классический Outlook показывает их сам («Оповещение на рабочем столе»).
- Режим **«Не беспокоить»** не мешает: уведомления всё равно записываются в базу.

## 4. Запусти помощника

Двойной щелчок по `stars_helper.exe`. Окна не будет, он работает в фоне. Проверка: открой в браузере http://127.0.0.1:8777/#wallpaper, справа должны быть часы, встречи и сообщения.

**Автозапуск:** нажми Win+R, введи `shell:startup`, Enter, и положи в открывшуюся папку ярлык на `stars_helper.exe`.

## 5. Поставь обои в Lively Wallpaper

1. Установи **Lively Wallpaper** из Microsoft Store (бесплатно).
2. В Lively нажми **«+»** (Добавить обои) → в поле «Введите URL» вставь `http://127.0.0.1:8777/#wallpaper` → Enter.
3. Выбери эти обои и нажми **«Установить как обои»**. Для нескольких мониторов выбери нужный экран.
4. В настройках Lively → **Производительность** можно оставить паузу обоев, когда открыто полноэкранное приложение. Так игры и видео не тормозят.

Можно и **Wallpaper Engine** (Steam): «Создать обои» → «Веб» → тот же адрес.

## Настройки `config.json`

| Поле | По умолчанию | Что делает |
|---|---|---|
| `ics_url` | `""` | ссылка ICS на календарь Outlook |
| `show_text` | `true` | `false` — показывать только отправителя, без текста сообщения |
| `max_notifications` | `12` | сколько сообщений хранить в ленте |
| `notification_hours` | `12` | за сколько часов показывать сообщения |
| `days_ahead` | `7` | на сколько дней вперёд брать встречи |
| `port` | `8777` | порт помощника (тогда поменяй адрес в Lively) |

После правки `config.json` перезапусти помощника.

## Если что-то не работает

- **Обои пустые или чёрные:** помощник не запущен. Запусти его и обнови обои в Lively.
- **Нет встреч:** проверь `ics_url` (открой ссылку в браузере, должен скачаться файл `.ics`). Календарь обновляется раз в 10 минут.
- **Нет сообщений WhatsApp:** уведомления WhatsApp Web выключены в браузере или в Windows, либо вкладка закрыта.
- **Видно лишнее:** обои видят все, кто подходит к компьютеру. Поставь `"show_text": false`.
- **Не поддерживается:** база уведомлений — внутренняя часть Windows 10 и 11. Её устройство Microsoft может изменить в обновлении. Если сообщения пропадут после обновления Windows, напиши.
